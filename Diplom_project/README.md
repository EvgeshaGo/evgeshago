Тема работы:

Анализ и прогнозирование стоимости акций на основе финансовых данных с использованием методов машинного обучения и статистического моделирования.

Цель работы:

Целью данной дипломной работы является анализ и прогнозирование стоимости акций, основанных на финансовых данных (ценах акций). В работе применяются методы машинного обучения и статистического моделирования для создания предсказательных моделей, анализа тенденций и выявления зависимостей между различными финансовыми показателями.

Задачи работы:

 1. Анализ стоимости акций: Исследование динамики цен акций различных компаний с использованием статистических методов и методов машинного обучения.
 2. Построение и оценка моделей: Использование линейных регрессионных моделей, ансамблевых методов и ARIMA для прогнозирования будущих значений на основе исторических данных.
 3. Оценка качества моделей: Применение различных метрик для оценки точности моделей, таких как средняя абсолютная ошибка (MAE), среднеквадратическая ошибка (RMSE) и другие.
 4. Проверка на стационарность: Проведение теста Дики-Фуллера для проверки стационарности временных рядов.
 5. Визуализация данных: Создание графиков для отображения тенденций, сезонных колебаний и остатков модели.

Методы исследования:

В работе использованы следующие методы:
 * Анализ временных рядов с применением статистических методов, таких как расчет корреляции, трендов и сезонности.
 * Модели машинного обучения для прогнозирования, включая линейную регрессию, случайный лес и градиентный бустинг.
 * Модели временных рядов типа ARIMA для прогнозирования будущих значений с учетом тренда и сезонности.
 * Статистические тесты, такие как тест Дики-Фуллера для проверки стационарности данных.
 * Визуализация данных с использованием библиотеки matplotlib и plotly для создания интерактивных графиков и анализа данных.

Используемые инструменты:

Для выполнения расчетов и анализа данных использовались следующие библиотеки Python:
 * pandas и numpy для обработки и манипуляции данными.
 * matplotlib, seaborn и plotly для построения графиков и визуализации данных.
 * sklearn для реализации методов машинного обучения, включая линейные модели и ансамблевые методы.
 * statsmodels для моделирования временных рядов и выполнения статистических тестов.
 * yfinance для загрузки исторических данных о ценах акций.
 * pickle для сохранения и загрузки обученных моделей.

Результаты работы:

 1. Было проведено исследование нескольких финансовых временных рядов (цен акций разных компаний).
 2. Прогнозирование цен акций было выполнено с использованием модели ARIMA и машинного обучения (случайный лес, градиентный бустинг).
 3. Для оценки точности моделей использовались различные метрики, такие как средняя абсолютная ошибка (MAE) и среднеквадратическая ошибка (RMSE).
 4. Тест Дики-Фуллера показал, что данные имеют некоторую стационарность, что позволило применить модель ARIMA для дальнейшего прогнозирования.
 5. Визуализация результатов с помощью графиков и корреляционных матриц позволила получить наглядное представление о трендах, сезонных колебаниях и зависимостях между различными компаниями.

  Заключение:

Данная работа продемонстрировала применение методов машинного обучения и статистического моделирования для анализа и прогнозирования стоимости акций. Результаты показывают, что использование моделей, таких как ARIMA и ансамблевые методы, позволяет эффективно прогнозировать цены акций, а также выявлять скрытые зависимости между различными компаниями.
